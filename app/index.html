🏛️ Apache Kafka 4.3.1 Local Broker Architecture

What is the purpose of Apache Kafka in this system?
In enterprise digital payments (UPI, Visa, Mastercard), transaction volume spikes to 50,000+ events per second. Traditional synchronous HTTP APIs crash under this load. Apache Kafka serves as the Zero-Loss Event Speed Layer:

1. Ingestion: Transactions are appended to "financial.transactions.stream" with sub-ms ACK.
2. Parallelism: 3 Partitions (P0, P1, P2) allow parallel consumer inference workers.
3. Reliability: Zero message loss and append-only auditability for regulatory compliance.
4. Dead-Letter Queue: Intercepted fraud is routed to "financial.fraud.alerts" for instant SMS lock!

Why can't Kafka open in Chrome?
Kafka speaks a high-performance binary TCP protocol on port 9092, not HTTP HTML. Opening http://localhost:9092 in Chrome sends HTTP headers that Kafka does not understand. This dashboard bridges Kafka's binary events into this visual browser application!
