REAL-TIME FINANCIAL FRAUD & CREDIT RISK INTELLIGENCE SYSTEM
Abstract:
Financial fraud presents a critical threat to global banking infrastructure, driving over 40 Billion USD in annual losses worldwide. Traditional rule-based legacy detection systems suffer from severe vulnerabilities, including an inability to adapt to zero-day fraud tactics, failure to uncover collusive multi-account fraud rings, severe class imbalance (~3.5% fraud ratio), and lack of decision explainability required for financial regulatory compliance.

To overcome these limitations, this capstone project proposes a multi-model ensemble intelligence framework for real-time financial fraud detection and credit risk scoring. The core architecture integrates five specialized AI models: (1) LightGBM — gradient boosted decision trees for high-speed tabular feature classification; (2) TabNet (Google Brain, 2019) — sequential attention deep learning for tabular reasoning; (3) AutoEncoder — deep neural reconstruction for zero-day anomaly detection; (4) ECOD (IEEE 2022) — empirical CDF-based unsupervised outlier scoring; and (5) Graph Attention Network (GAT) — PyTorch Geometric graph neural network for mapping transaction networks and identifying fraud rings.

CTGAN (Generative AI) is leveraged to generate privacy-safe synthetic fraud data to solve severe class imbalance. The weighted ensemble outputs a real-time Risk Score (0–100) per transaction deployed via containerized FastAPI with SHAP explainability audit trails and a Streamlit live dashboard.
Keywords: Financial Fraud Detection, Graph Attention Networks (GAT), TabNet, LightGBM, CTGAN, FinTech, Explainable AI
