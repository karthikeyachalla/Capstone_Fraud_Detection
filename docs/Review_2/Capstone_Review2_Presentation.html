Tri-Model Machine Learning Fusion Architecture

1. LightGBM Supervised
Paradigm: Supervised Boosting
Leaf-wise gradient boosting optimized for high-speed tabular feature split evaluation.
ROC-AUC: 0.9177
Primary workhorse for single-row transaction risk scoring.
2. PyTorch AutoEncoder
Paradigm: Unsupervised Anomaly
Deep bottleneck neural network detecting zero-day fraud via Reconstruction Error (MSE).
ROC-AUC: 0.8450
Unsupervised baseline capturing unknown fraud patterns.
3. Graph GAT (PyTorch PyG)
Paradigm: Relational Graph Network
Multi-head attention mechanism mapping shared card IDs & emails to detect multi-account fraud rings.
ROC-AUC: 0.8920
Uncovers coordinated money-laundering syndicates.

GRAPH NEURAL NETWORK INTEGRATION

PyTorch Geometric GAT for Fraud Ring Detection

Graph Node & Edge Construction
Transaction Nodes
Every financial transaction is modeled as a node embedded with its engineered tabular features.
Identity Edge Connections
Edges are drawn between transactions sharing identity attributes: Card ID (`card1`), billing zip (`addr1`), and email domain (`P_emaildomain`).
Multi-Head Attention Weights
Dynamic Attention Coefficients
Multi-head attention mechanisms assign higher edge weights to suspicious shared nodes across network clusters.
Uncovering Organized Fraud Rings
Detects collusive multi-account money laundering and stolen identity syndicates invisible to single-row models.
PyTorch Geometric Implementation (`src/03_gat_model.py`)
Built modular Graph Attention Network script using PyTorch Geometric (PyG). Model weights trained and exported directly to `models/gat_model.pt` for production API inference.
