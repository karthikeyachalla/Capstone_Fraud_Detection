1. Executive Summary

This report documents the completion of Review 2 deliverables for the Capstone project. The theoretical pipeline presented in Review 1 has been realized into a fully functional, local Python training system using the IEEE-CIS financial fraud dataset structure. The system features a 3-model fusion engine, sub-20ms FastAPI inference endpoint, SHAP audit logs, and Kafka streaming simulator.

2. System Architecture & Tri-Model Core

STAGE 01: Data Ingestion (IEEE-CIS Transactions & Kafka Streaming Simulator) STAGE 02: Preprocessing & Scaling (Log Amount, Frequency Encoding, StandardScaler) STAGE 03: Tri-Model Core (CatBoost GBDT 70% + PyTorch AutoEncoder 15% + PyTorch GCN 15%) STAGE 04: Risk Synthesis & Explainable AI (SHAP attributions per transaction) STAGE 05: FastAPI Microservice Gateway (sub-100ms REST endpoint: http://127.0.0.1:8000/predict)
